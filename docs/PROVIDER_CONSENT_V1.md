# Provider consent v1

Version: provider-consent-v1. Scopes stored separately; no implicit opt-in for legacy users.

APPLICATION_REVIEW: the applicant permits Mộc Maria to use application information, experience and contact details to review the application, organize training and assess it. Application submission does not grant a regulated practice right or permission to receive bookings.

PUBLIC_PROFILE: the applicant permits approved, eligible public professional name, introduction/experience and service area to be published. Private contact details, identity documents and home addresses are excluded. Portrait/media publication requires the separate media safety/consent workflow.

The applicant can withdraw either scope. Public visibility requires both current scopes and valid contact/certificate/profile; withdrawal hides immediately. Consent changes are versioned and audited. It does not delete records required for accountable review/history. Owner must define privacy/retention policy before full operation.

Admin contact evidence records refer to documented communication through an existing account channel; the admin must check control of the channel. No self-attestation by KTV is accepted. OTP/email delivery remains a separate future integration.
