# Detailed training / assessments / renewal — D2
Status: D2 deployed and verified on2026-10-09; E1 is now active.

Migration14 TrainingAssessmentEvidence1791642400000 adds required module minutes, a monotonic course requirements revision, practical criteria, immutable assessment attempts, current-assessment pointers and immutable certificate issuance/renewal history. Existing certificate facts are copied as IMPORTED history; no evidence is invented and those facts do not automatically satisfy detailed training validity.

Owners configure actual required training minutes and practical minimum scores; missing required volume or missing required criteria blocks assessment completion. Attendance comes from ended, completed, actively assigned sessions and recorded PRESENT minutes. Each required active module needs at least80% of its defined minutes; extra time in one module cannot compensate for a deficient different module. Total attendance caps each module at its defined volume. No percentage or pass flag is accepted from the assessment client.

An independent assessor explicitly confirms actual practical evidence, records a safe internal reference/reason/valid-until date and scores the current criteria. Required criteria must all be scored; unknown/duplicate criteria are rejected. The server derives pass/fail from attendance and scores. Every attempt stores its criteria/attendance snapshot, requirements revision and evidence fingerprint. Failed attempts and reassessments remain in history. The obsolete manual-percentage assessment endpoint rejects writes.

Issuance requires a current passed assessment and an explicit expiry no later than the assessment expiry. Renewal requires a new passed assessment after the previous issue, a never-used certificate number and explicit confirmation/reason. The current certificate ID stays stable for skill references; old numbers/dates/assessment references are preserved in issuance history. Concurrent renewal is serialized with the provider application and course locks. A revoked certificate additionally requires the application to return to ASSESSMENT and new practical assessment after revocation; renewal does not approve the application or restore service access by itself.

Certificate validity is re-evaluated against current module/criterion requirements, course revision and attendance facts. Changes invalidate old evidence even if the requirements are later restored; identical semantic saves do not increase revision. Expired/failed/revoked/missing/changed evidence blocks approval, skill activation and public service eligibility. Public eligibility also requires an active required practical criterion explicitly linked to the requested service, alongside C2 service/branch/course/legal/territory/quality/consent/contact/schedule gates.

Admin GET routes are staff.manage and private,no-store; mutations are roles.manage. Self-assessment, self-issue and self-renew are denied. Own training returns only owned enrollment/current summary/certificate data, omits assessor/issuer identities and never returns assessment evidence references, reason/history or score snapshots. Admin-only history remains private. No production training/customer/provider fixtures are added; actual business data and professional/legal review remain owner responsibilities.
